# Jarvis-Examples

The Git repository contains the live [official project catalog](catalog/) for
Jarvis and links to the corresponding GitHub Release assets. Project worktrees
are intentionally local-only and ignored by Git; publish a `.tar.gz` or
encrypted `.tar.gz.jenc` as a Release asset, then add its URL to the catalog.
Local release files are ignored and uploaded explicitly rather than committed.

See [catalog/README.md](catalog/README.md) for the catalog and release contract.
